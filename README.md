Information Retrieval System
🧩 Overview
Information Retrieval System is a lightweight web application developed as part of an academic project in the Information Retrieval course.

Built using Vanilla HTML, CSS, and JavaScript, the system allows users to search through a curated set of 33 documents, supporting both Arabic and English content. It implements a basic Boolean retrieval model and provides a sleek, responsive interface.

🚀 Features
🔍 Live Search: Instantly updates results as the user types.

🌐 Bilingual Support: Works seamlessly with both Arabic and English documents.

🌙 Dark Mode: Toggle between light/dark themes with a user-friendly ☀️/🌙 icon.

📱 Responsive Design: Adapts to all screen sizes with RTL (Right-to-Left) support for Arabic.

✅ Boolean Retrieval Model: Uses includes() to match query keywords with document titles and contents.

📄 On-Demand Display: Documents remain hidden until a search is performed.

🧠 Rich Content Base: 33 documents covering topics like:

Artificial Intelligence

Information Retrieval

Big Data

Cloud Computing

Frontend & Backend Development
